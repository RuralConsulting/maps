      Set up two-factor sign-in

      RCL staff accounts need a 6-digit code from an authenticator app as well as the password. You only set this up once.

      1. On your phone, install Microsoft Authenticator or Google Authenticator (free).
      2. In the app, add an account and scan this code.
      3. Type the 6-digit code the app shows.

        QGIS plugin

        The RCL Web Package plugin builds farm maps in QGIS and publishes them here.

        Install it (once)

        1. In QGIS: Plugins > Manage and Install Plugins > Settings.
        2. Under Plugin Repositories click Add…. Name: RCL. URL: . Click OK.
        3. Go to All, search for RCL Web Package and click Install Plugin. QGIS tells you when there's an update.
        4. Open the plugin, click Sign in… and use your RCL email, your portal password and the code from your authenticator app.

        Or download the plugin ZIP and use Install from ZIP (you won't be told about updates).

        There's no secret key to copy: what you can do is set by your role on the Staff page.
