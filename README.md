# RCL client map portal (built site)

The finished files for https://maps.ruralconsulting.co.nz, served by GitHub Pages. Nothing here is secret: it's exactly
what a visitor's browser downloads. Customer maps, logins and data live in Supabase behind sign-in.

Don't edit these files by hand. The source is in the private `rcl-map-portal` repo; run `portal/build.sh` there and copy
`portal/dist/` here to update the site.
